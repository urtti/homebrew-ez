# Homebrew Tap for ez

```sh
brew install urtti/ez/ez
```

The full name adds the urtti/ez tap and tells Homebrew to trust this one formula from it. If you tapped urtti/ez before Homebrew 6 and `brew upgrade ez` now says "Refusing to load formula urtti/ez/ez from untrusted tap", run `brew trust --formula urtti/ez/ez` once.

For documentation and usage, see [urtti.com/ez](https://urtti.com/ez).
